CAUSAL STATE-DEPENDENT LOCAL PROJECTIONS
Participant materials — Weining Wang and Xiyu Jiao

1. Install R (4.1 or newer recommended). RStudio is optional.
2. Extract the entire ZIP before opening files. Keep the folder structure.
3. Open Local_Projections.Rproj in RStudio, or start R in this folder.
4. Run source("code/R/check_setup.R"). It should print SETUP CHECK PASSED.
5. Open exercises/R_Exercises_Handout.pdf and exercises/participant_template.R.
6. Work through the four core tasks, designed for 30 minutes.

The core practical uses only base R and the recommended splines package.
All data are synthetic and are generated by the setup script. No data download,
API key, GitHub login or ChatGPT account is needed after downloading the pack.

Optional notebook: open exercises/Participant_Notebook.Rmd. Run its chunks in
order. To knit an HTML copy, install rmarkdown once. In RStudio this also uses
the bundled Pandoc. The notebook sets its working directory to the pack root.
If using rmarkdown::render, call it from this folder:
  rmarkdown::render("exercises/Participant_Notebook.Rmd")

Optional extensions cover later horizons, bandwidth sensitivity, endogenous
initial states and finite shock shifts. Simultaneous bands are over the
specified state grid at ONE horizon, not jointly over all horizons.
The exercise does not establish causal identification for an empirical dataset.

Solutions are a separate download on the website. The participant ZIP contains
the unanswered handout and template, not the instructor solutions.
