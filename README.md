# Local projections: course website

Public GitHub Pages site for Weining Wang and Xiyu Jiao's teaching materials.

- Start at index.html or download R_Exercises_Participant_Pack.zip.
- All_Teaching_Materials.zip contains the research talk, course slides, notes,
  exercises, solutions, reproducible R code and editable LaTeX sources.
- Research_Talk_Pack.zip and Short_Course_Slides_and_Notes.zip are separate bundles.
- R_Worked_Solutions.zip contains answer scripts and reference results.
- R_Demo_Code.zip contains the core demo and advanced quadratic/cubic examples.

Extract ZIPs before running R. Source the code from the extracted folder root.
The participant pack has no instructor solutions. All practical data are synthetic.
The original private project remains a separate repository.

Published PDFs and core R scripts preserve the existing teaching versions.
This website, quick-start guide and participant notebook were prepared 13 November 2026.
