BEFORE YOU ARRIVE

Your first five minutes in R.

Download setup guide ↓
  1. Download and extract

    Save the participant ZIP and extract the whole folder. Keep its directory structure.

  2. Open the project

    Open Local_Projections.Rproj in RStudio, or start R in the extracted folder.

  3. Check your setup

    Run the command below. The core practical needs only base R and splines.

  4. Start the exercises

    Open the PDF handout and exercises/participant_template.R. The optional R Markdown notebook supports chunk-by-chunk work.

RUN FROM THE EXTRACTED FOLDER
source("code/R/check_setup.R")

All practical data are synthetic.

The setup generates the panel locally. No empirical dataset, API key or account is required.

For the notebook’s Knit button, install rmarkdown. This is optional for the core R scripts.

Running the solutions and the larger demonstrations

Download All teaching materials and run from the extracted folder:

source("exercises/instructor_solutions.R")
source("code/R/run_course.R")

The first script regenerates the core answers. The second estimates horizons 0–8 and writes figures, CSV results and a synthetic data file. For the separate advanced quadratic/cubic examples, open advanced_demo/README.txt, install its listed packages, run the setup check, then the two demos before the advanced exercises.

How to interpret the uncertainty measures

The simultaneous band covers a specified state grid at one horizon; it is not a joint band over all horizons. AIC selection alone does not ensure approximation-bias control. The exercises do not establish empirical causal identification, account for generated shocks or resolve weak instruments. A comparison across initial states is not an intervention on the state.
